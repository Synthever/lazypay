Payment Gateway Integration

Dokumentasi API & Integrasi

Gunakan dokumentasi ini untuk menghubungkan bot Telegram, toko online, website SaaS, atau aplikasi backend lainnya ke GusPay Autonomous Payment Gateway.

BASE URL
https://gus-pay.rkhyg.xyz
AUTH HEADER
x-api-key: YOUR_SECRET_KEY
FORMAT
JSON (application/json)
POST /api/v1/invoices

Membuat tagihan pembayaran QRIS baru. Server akan mengalokasikan kode unik dan membuat tautan halaman pembayaran (checkout URL).

Request Body:
{
  "orderId": "ORDER-9912",
  "amount": 50000,
  "customerName": "Rey Synthever",
  "customerEmail": "rey@rkhyg.xyz",
  "description": "Pembelian Paket VIP",
  "callbackUrl": "https://toko-kamu.com/api/payment-callback"
}
Response (201 Created):
{
  "success": true,
  "message": "Invoice berhasil dibuat",
  "data": {
    "invoiceId": "INV-MTN748F8-VWAO",
    "orderId": "ORDER-9912",
    "baseAmount": 50000,
    "uniqueCode": 217,
    "totalAmount": 50217,
    "status": "PENDING",
    "expiredAt": "2026-09-04T18:30:00.000Z",
    "checkoutUrl": "https://gus-pay.rkhyg.xyz/pay/INV-MTN748F8-VWAO"
  }
}
WEBHOOK Payment Success Webhook Event

Ketika pembeli berhasil mentransfer nominal tagihan ke QRIS DANA Bisnis, GusPay akan mengirimkan HTTP POST otomatis ke callbackUrl milikmu.

Payload Diterima:
{
  "event": "payment.success",
  "data": {
    "invoiceId": "INV-MTN748F8-VWAO",
    "orderId": "ORDER-9912",
    "baseAmount": 50000,
    "uniqueCode": 217,
    "totalAmount": 50217,
    "status": "PAID",
    "paidAt": "2026-09-04T18:15:20.123Z",
    "customerName": "Rey Synthever"
  },
  "timestamp": "2026-09-04T18:15:20.125Z"
}

Contoh Integrasi Code

Node.js (Fetch / Axios) 
const response = await fetch('https://gus-pay.rkhyg.xyz/api/v1/invoices', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': 'guspay_sec_your_secret_api_key'
  },
  body: JSON.stringify({
    orderId: 'INV-001',
    amount: 10000,
    customerName: 'Rey',
    callbackUrl: 'https://mywebsite.com/api/payment-callback'
  })
});
const result = await response.json();
console.log('Buka URL Pembayaran:', result.data.checkoutUrl);
PHP / Laravel (Http Client) 
use Illuminate\Support\Facades\Http;

$response = Http::withHeaders([
    'x-api-key' => 'guspay_sec_your_secret_api_key'
])->post('https://gus-pay.rkhyg.xyz/api/v1/invoices', [
    'orderId' => 'INV-001',
    'amount' => 10000,
    'customerName' => 'Rey',
    'callbackUrl' => 'https://mywebsite.com/api/payment-callback'
]);

$checkoutUrl = $response->json('data.checkoutUrl');
