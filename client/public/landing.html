Workflow Architecture

Alur Kerja LazyPay

Sederhana, aman, dan tanpa perlu login session scraping yang rawan checkpoint.

1

Generate Dynamic QRIS

LazyPay mengambil QRIS Statis tokomu, menyuntikkan nominal pas beserta 3 digit kode unik (Tag 54), dan menghitung ulang checksum CRC16 EMVCo.

2

Pembeli Scan & Bayar

Pembeli memindai QRIS menggunakan m-Banking (BCA, Mandiri, BRI) atau e-wallet (DANA, Gopay, ShopeePay). Nominal terkunci otomatis di aplikasi pembeli.

3

Notif Listener & Webhook

Aplikasi Android Forwarder menangkap push notifikasi masuk dari DANA Bisnis, meneruskannya ke server, lalu invoice otomatis terverifikasi PAID.

Capabilities

Fitur Utama Platform

Protected Dashboard

Keamanan tingkat tinggi dengan JWT session HTTP-only, enkripsi bcrypt, dan sensor string QRIS di server.

Unique Code Pool

Mengalokasikan kode unik 1–499 yang belum terpakai invoice aktif guna menghindari bentrok transaksi.

Lightweight Forwarder APK

Aplikasi background listener hemat daya baterai dengan filter khusus notifikasi DANA Bisnis.

Instant Outbound Webhook

Kirim callback payload status transaksi sukses ke backend aplikasimu dengan secret verification header.

WebSocket Live Reload

Halaman checkout pembeli dan dashboard admin otomatis terupdate secara realtime tanpa refresh manual.

RESTful Developer API

Endpoint API yang mudah diintegrasikan dengan bahasa apapun (PHP, Node.js, Python, Golang, cURL).
